Natours

A RESTful API for tour booking and management built with Node.js, Express, and MongoDB. Natours provides comprehensive endpoints for managing tours and their associated data with a modern, scalable backend architecture.

## Features

- **Tour Management**: Full CRUD operations for tours (Create, Read, Update, Delete)
- **Advanced Filtering**: Query tours with dynamic filtering, sorting, and pagination support
- **RESTful API**: Clean, well-structured REST API following standard conventions
- **Data Validation**: Schema-based validation using Mongoose for data integrity
- **Error Handling**: Consistent error responses with meaningful status codes and messages
- **Development Ready**: Includes Morgan HTTP request logging for development environments
- **Modular Architecture**: Organized separation of concerns with controllers, models, and routes

## Tech Stack

- **Runtime**: Node.js with ES Modules (type: "module")
- **Framework**: Express.js v5.2.1
- **Database**: MongoDB with Mongoose v9.9.5
- **HTTP Logging**: Morgan v1.12.0
- **Development**: Nodemon v3.1.14 for auto-restart
- **Environment Management**: dotenv v17.4.2
